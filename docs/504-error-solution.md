# 504エラー（Gateway Timeout）の解決方法

## エラーの原因

504エラーは、Supabaseのメール送信サービスがタイムアウトしていることを示しています。これは通常、以下の原因で発生します：

1. **SupabaseのデフォルトSMTPが設定されていない**
   - 無料プランでは、デフォルトのSMTP設定が不完全な場合があります

2. **カスタムSMTPが設定されていない**
   - カスタムSMTPを設定していない場合、メール送信が失敗する可能性があります

3. **SMTP設定が正しくない**
   - 設定したSMTPサーバーに接続できない場合

4. **Supabaseのメール送信サービスが一時的に利用できない**
   - まれに、Supabaseのサービスが一時的にダウンしている場合があります

## 解決方法

### 方法1: カスタムSMTPを設定する（推奨）

**最も確実な解決方法は、GmailなどのカスタムSMTPを設定することです。**

#### Gmail SMTPの設定

1. **Gmailアプリパスワードを取得**
   - https://myaccount.google.com/security にアクセス
   - 「2段階認証プロセス」を有効化
   - 「アプリパスワード」を生成
   - 16文字のパスワードをコピー

2. **SupabaseでSMTP設定**
   - Supabaseダッシュボード → 「Authentication」→「Settings」
   - 「SMTP Settings」セクションを開く
   - 「Enable Custom SMTP」をONにする
   - 以下の設定を入力：

```
Host: smtp.gmail.com
Port: 587
Username: 【あなたのGmailアドレス】
Password: 【16文字のアプリパスワード】
Minimum interval per user: 60
```

3. **送信者情報を設定**
   - 「Sender email」: あなたのGmailアドレス
   - 「Sender name」: FD GROUP 勤怠管理システム

4. 「Save」をクリック

詳細は `docs/free-smtp-setup.md` を参照してください。

### 方法2: しばらく待ってから再試行

一時的な問題の可能性があるため、数分待ってから再度試してください。

### 方法3: Supabaseダッシュボードで確認

1. Supabaseダッシュボードにログイン
2. 「Authentication」→「Users」を開く
3. パスワードリセットをリクエストしたユーザーを検索
4. メール送信履歴を確認
5. エラーメッセージがないか確認

## エラーメッセージの改善

アプリのエラーハンドリングを改善し、504エラーが発生した場合に適切なメッセージを表示するようにしました：

- **504エラーの場合**: 「サーバーからの応答がタイムアウトしました。Supabaseのメール送信設定を確認してください」というメッセージを表示
- **解決方法の案内**: エラーメッセージに解決方法へのリンクを表示

## 予防策

1. **カスタムSMTPを設定する**
   - Gmail、SendGrid、MailgunなどのSMTPプロバイダーを設定
   - 無料プランでも利用可能

2. **定期的にテストする**
   - パスワードリセット機能を定期的にテスト
   - メールが正常に送信されるか確認

3. **モニタリング**
   - Supabaseダッシュボードでメール送信ログを確認
   - エラーが発生していないか確認

## まとめ

504エラーは、Supabaseのメール送信設定が不完全な場合に発生します。**カスタムSMTP（Gmail推奨）を設定することで、この問題を解決できます。**

設定方法の詳細は `docs/free-smtp-setup.md` を参照してください。
