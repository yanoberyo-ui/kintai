## 4. 既知の問題・注意点

### 認証要件
- 管理者画面は`is_minigame_admin`権限が必要
- E2Eテストでは認証バイパスまたはテストユーザー設定が必要

### ブラウザ互換性
- Chrome/Edge: 動作確認済み想定
- Safari: Realtimeのwss接続確認が必要
- Firefox: 動作確認推奨

### パフォーマンス
- 参加者50人以上での負荷テスト未実施
- Realtime購読数の制限確認が必要

### セキュリティ
- イベントIDがUUID形式で推測困難
- セッションIDはlocalStorageに保存（XSS注意）
