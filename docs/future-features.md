# 今後実装予定の機能

このドキュメントは、FDGroup勤怠管理システムに今後追加予定の機能をまとめたものです。

## 🔥 優先度：高（近日中に実装）

### 1. 再出勤ボタン
**概要**: 退勤後に再度出勤できる機能

**要件**:
- 退勤完了後に「再出勤」ボタンを表示
- 押すと新しい勤怠レコードを作成（または同日の既存レコードを更新）
- Slack通知も送信

**技術的詳細**:
- `status: 'completed'` の場合のみ表示
- 新規レコード作成 or 既存レコードの `clock_out` をnullに戻す
- UI: 退勤完了メッセージの下に配置

---

### 2. ポモドーロタイマー機能
**概要**: タスクと紐付いたポモドーロタイマー

**基本仕様**:
- 25分作業 → 5分休憩のサイクル
- 4ポモドーロ完了後は15分の長い休憩
- タイマー終了時に音 + ブラウザ通知

**UI設計**:
- 配置: TODOリストの上部、または各タスクの横
- 作業中: 🍅 + カウントダウン表示
- 休憩中: ☕ + カウントダウン表示
- ポモドーロ完了数: 各タスクに「🍅×3」のように表示

**データベース変更**:
```sql
-- todo_itemsテーブルに追加
ALTER TABLE todo_items ADD COLUMN pomodoro_count INTEGER DEFAULT 0;

-- ポモドーロ履歴テーブル（オプション）
CREATE TABLE pomodoro_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  todo_item_id UUID REFERENCES todo_items(id),
  started_at TIMESTAMPTZ NOT NULL,
  completed_at TIMESTAMPTZ,
  duration_minutes INTEGER DEFAULT 25,
  session_type VARCHAR(20) CHECK (session_type IN ('work', 'short_break', 'long_break')),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**追加機能**:
- 集中モード: ポモドーロ中は他のタスクを選択不可
- 統計: 1日の合計ポモドーロ数をダッシュボードに表示
- ランキング: ポモドーロ完了数もスコアに加算

**参考ライブラリ**:
- Web Audio API（タイマー音）
- Notification API（ブラウザ通知）

---

### 3. タスクのドラッグ&ドロップ並び替え
**概要**: タスクをドラッグして順序を変更、親子関係も保持

**要件**:
- ドラッグ&ドロップで `order_index` を更新
- **親todoを移動 → 子todoも一緒に移動**
- インデントされた子todoは親の直下に配置される

**技術スタック**:
- `@dnd-kit/core` または React DnD
- ドロップ時に `order_index` を再計算してバックエンドに送信

**実装の注意点**:
- 親子関係の判定ロジック
- 親を移動した時、子todoの `order_index` も連動して更新
- アニメーションでスムーズに移動

---

### 4. 親子todoの繋がりを示すインデント線
**概要**: 親子関係を視覚的に分かりやすくする

**UI設計**:
```
📝 親タスク
│
├─ 📝 子タスク1
│
└─ 📝 子タスク2
```

**実装方法**:
- CSSで縦線を描画（`border-left` + `::before` 疑似要素）
- インデントレベルに応じて線の位置を調整
- 色: `border-gray-300` (light mode), `border-gray-700` (dark mode)

**参考デザイン**:
- VS Codeのファイルツリー
- Notionの階層表示

## 📊 優先度：中（1-2週間以内）

### 5. ストリーク機能
**概要**: 連続出勤日数や連続達成率を表示

**表示項目**:
- 🔥 連続出勤日数
- 🎯 連続タスク達成率90%以上の日数
- 💪 連続ポモドーロ4個以上完了の日数

**UI配置**:
- ダッシュボードまたはプロフィールページ
- 炎アイコン🔥 + 数字で表示
- 過去最高記録も表示

**データ計算**:
- 毎日の勤怠データから連続日数を計算
- ストリークが途切れたら0にリセット
- 週末・祝日はカウントしない（設定可能に）

**モチベーション施策**:
- 7日ストリーク達成でバッジ獲得
- ストリーク更新時にお祝いアニメーション

---

### 6. チーム全体のランキング表示
**概要**: メンバーページに週間・月間ランキングを追加

**ランキング種類**:
- 📅 週間ランキング（今週の頑張り度）
- 📆 月間ランキング（今月の頑張り度）
- 🏆 殿堂入り（歴代1位獲得回数）
- 🍅 ポモドーロ王（今週の合計ポモドーロ数）

**UI設計**:
- メンバーページの上部にタブ切り替え
- 「今日」「今週」「今月」「歴代」
- 表彰台デザイン（1位は大きく、2位3位は小さく）

**データ保存**:
```sql
-- ランキング履歴テーブル
CREATE TABLE ranking_history (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  date DATE NOT NULL,
  daily_rank INTEGER,
  score DECIMAL(10, 2),
  task_count INTEGER,
  completion_rate INTEGER,
  pomodoro_count INTEGER,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, date)
);
```

### 7. 異常値検知機能
**概要**: 長時間勤務や休憩なしを検知して警告

**検知パターン**:
- ⚠️ 12時間以上の連続勤務
- ⚠️ 休憩時間0分
- ⚠️ 深夜勤務（22時以降も作業中）
- ⚠️ 週の勤務時間が60時間超え

**通知方法**:
- リアルタイム通知（本人 + 管理者）
- Slack通知
- ダッシュボードに警告バッジ表示

**管理者ビュー**:
- 異常値一覧ページ
- フィルター機能（種類、期間）
- CSV出力

**実装**:
- 退勤時にチェック
- バックグラウンドで定期的にスキャン（1時間ごと）
- Supabase Edge Functionで実装
