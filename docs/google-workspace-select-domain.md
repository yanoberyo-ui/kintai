# Google Workspaceでforestdali.bizを選択する方法

Google Workspace管理コンソールでforestdali.bizドメインを選択する具体的な手順を説明します。

## 方法1: Google Workspace管理コンソールから（直接URL）

### ステップ1: ドメイン設定画面にアクセス

1. **以下のURLにアクセス**
   ```
   https://admin.google.com/ac/domains/manage
   ```
   または
   ```
   https://admin.google.com/ac/domains
   ```

2. **表示される画面**
   - ドメインの一覧が表示されます
   - 「forestdali.biz」というドメイン名が表示されているはずです

### ステップ2: forestdali.bizをクリック

1. **ドメインリストを確認**
   - 画面に表示されているドメインのリストを確認
   - 「forestdali.biz」というテキストを探す

2. **forestdali.bizをクリック**
   - 「forestdali.biz」のテキストまたは行全体をクリック
   - これでforestdali.bizの詳細設定画面に移動します

### ステップ3: DNS設定を開く

forestdali.bizの詳細画面で：

1. **「DNS設定」タブを探す**
   - 画面の上部または左側にタブがある場合、「DNS設定」または「DNS」タブをクリック

2. **または「DNSレコード」セクションを探す**
   - 画面をスクロールして「DNSレコード」セクションを探す

## 方法2: Google Domainsから（推奨）

Google Domainsの方がDNS設定が簡単です。

### ステップ1: Google Domainsにアクセス

1. **Google Domainsにアクセス**
   ```
   https://domains.google.com
   ```

2. **Googleアカウントでログイン**
   - Google Workspaceと同じアカウントでログイン

### ステップ2: ドメインリストを確認

1. **ホーム画面を確認**
   - ログイン後、ホーム画面にドメインのリストが表示されます
   - 「My domains」または「ドメイン」セクションを確認

2. **forestdali.bizを探す**
   - ドメインリストの中に「forestdali.biz」が表示されているはずです

### ステップ3: forestdali.bizをクリック

1. **forestdali.bizをクリック**
   - 「forestdali.biz」のカードまたはテキストをクリック
   - これでforestdali.bizの管理画面に移動します

### ステップ4: DNS設定を開く

1. **「DNS」タブをクリック**
   - 画面の上部にタブがある場合、「DNS」タブをクリック
   - または左メニューから「DNS」を選択

2. **「カスタムリソースレコード」セクションを開く**
   - ページをスクロールして「カスタムリソースレコード」セクションを見つける
   - または「カスタムレコード」セクションを探す

## 方法3: Google Workspace管理コンソールの検索から

### ステップ1: 検索バーを使用

1. **Google Workspace管理コンソールの上部の検索バーをクリック**
   - 画面上部に検索バーがあります

2. **「forestdali」と入力**
   - 検索バーに「forestdali」と入力
   - または「DNS」と入力

3. **検索結果から選択**
   - 検索結果に「forestdali.biz」が表示されたらクリック

## 画面の見方

### Google Workspace管理コンソールの場合

ドメイン設定画面では、通常以下のような表示になります：

```
┌─────────────────────────────────────┐
│ ドメイン                              │
├─────────────────────────────────────┤
│ forestdali.biz          [詳細] [設定]│
│ example.com              [詳細] [設定]│
└─────────────────────────────────────┘
```

「forestdali.biz」の行をクリックすると、詳細設定画面に移動します。

### Google Domainsの場合

Google Domainsのホーム画面では、通常以下のような表示になります：

```
┌─────────────────────────────────────┐
│ My domains                           │
├─────────────────────────────────────┤
│ ┌─────────────┐  ┌─────────────┐   │
│ │forestdali.biz│  │example.com  │   │
│ │   [管理]    │  │   [管理]    │   │
│ └─────────────┘  └─────────────┘   │
└─────────────────────────────────────┘
```

「forestdali.biz」のカードをクリックすると、管理画面に移動します。

## 見つからない場合の対処法

### forestdali.bizが表示されない場合

1. **別のGoogleアカウントでログインしている可能性**
   - forestdali.bizを管理しているGoogleアカウントでログインしているか確認
   - 必要に応じて、正しいアカウントに切り替え

2. **権限の問題**
   - 管理者権限が必要です
   - スーパー管理者でログインしているか確認

3. **ドメインが別の場所で管理されている可能性**
   - WHOISで確認（https://whois.net）
   - ネームサーバーを確認して、DNSプロバイダーを特定

## 次のステップ

forestdali.bizを選択したら：

1. **DNS設定画面を開く**
   - 「DNS設定」または「DNS」タブをクリック

2. **カスタムレコードセクションを開く**
   - 「カスタムリソースレコード」または「カスタムレコード」セクションを探す

3. **ResendのDNSレコードを追加**
   - Resendダッシュボードに表示されているDNSレコードを追加

## まとめ

forestdali.bizを選択する方法：

1. ✅ **Google Domains（推奨）**: https://domains.google.com → ドメインリストからforestdali.bizをクリック
2. ✅ **直接URL**: https://admin.google.com/ac/domains/manage → ドメインリストからforestdali.bizをクリック
3. ✅ **検索機能**: 検索バーに「forestdali」と入力 → 検索結果から選択

**最も簡単な方法は、Google Domains（https://domains.google.com）にアクセスして、ドメインリストからforestdali.bizをクリックすることです。**
