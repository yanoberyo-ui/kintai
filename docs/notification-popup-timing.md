# 通知ポップアップの表示タイミング

このドキュメントでは、各通知ポップアップが表示されるタイミングを説明します。

## 1. イベント投票通知（🎉 新しいイベント！）

### 表示条件
- `category` が `'event'` のイベント
- `voting_deadline`（投票期限）が設定されている
- まだ閉じていない（`notification_dismissals`テーブルに記録されていない）

### 表示タイミング

#### リアルタイム表示
- **新しいイベントが作成された瞬間**に表示されます
- リアルタイム監視により、他のユーザーがイベントを作成すると即座にポップアップが表示されます

#### ホームページに戻った時
- ホームページ（`currentPage === 'home'`）に遷移した時にチェックされます
- 投票期限のあるイベントのうち、まだ閉じていない最新のものが表示されます
- 最新10件の中から、閉じていない最初のイベントが選ばれます

### コード位置
- リアルタイム監視: `src/App.jsx` 305-350行目
- ホームページチェック: `src/App.jsx` 561-586行目

---

## 2. 当日イベント通知（📅 今日はイベント当日！）

### 表示条件
- `category` が `'event'` のイベント
- `event_date`（イベント日時）が今日の日付
- 自分が参加登録済み（`announcement_participants`テーブルに記録されている）
- まだ閉じていない

### 表示タイミング

#### 初回チェック
- **ログイン時**に実行されます
- 今日のイベントをチェックして、参加登録済みのイベントがあれば表示します

#### 定期チェック
- **1時間ごと**に自動的にチェックされます
- ページを開いている間、バックグラウンドで実行されます

### コード位置
- `src/App.jsx` 397-449行目

## 4. フォローアップメッセージ通知（💬 新着メッセージ）

### 表示条件
- `event_follow_up_messages`テーブルに新しいメッセージが作成された
- 自分が対象である：
  - `target_type === 'all_participants'`: イベントの参加者である
  - `target_type === 'date_option_voters'`: 特定の日程に投票している
- まだ閉じていない

### 表示タイミング

#### リアルタイム表示
- **新しいフォローアップメッセージが作成された瞬間**に表示されます
- リアルタイム監視により、イベント作成者がメッセージを送信すると即座にポップアップが表示されます

#### ホームページに戻った時
- ホームページに遷移した時にチェックされます
- 最新10件のフォローアップメッセージの中から、自分が対象で閉じていない最初のものが表示されます

### コード位置
- リアルタイム監視: `src/App.jsx` 451-521行目
- ホームページチェック: `src/App.jsx` 614-652行目

## 共通の動作

### 非表示状態の管理
- すべての通知は、一度閉じると `notification_dismissals` テーブルに記録されます
- 記録された通知は、**二度と表示されません**
- デバイス間で共有されるため、別のデバイスで閉じた通知も表示されません

### 優先順位
複数の通知が同時に表示される可能性がある場合：
1. 既に表示中の通知がある場合は、新しい通知は表示されません
2. ホームページに戻った時は、既に表示中の通知が非表示になっているかチェックし、非表示なら閉じます

### ホームページでのチェック
- `currentPage === 'home'` の時に実行されます
- `user` と `currentPage` が変更されるたびに実行されます
- 既に表示中の通知がある場合は、新しい通知を表示しません

## トラブルシューティング

### 通知が表示されない場合
1. `notification_dismissals` テーブルを確認してください
2. 通知の条件（投票期限、参加登録など）を満たしているか確認してください
3. ブラウザのコンソールでエラーがないか確認してください

### 通知が繰り返し表示される場合
1. `notification_dismissals` テーブルへの保存が失敗していないか確認してください
2. RLSポリシーが正しく設定されているか確認してください
