# TODO機能 視覚化・履歴機能 ロードマップ

**最終更新**: 2025年11月11日
**目的**: やることと、やったことをパッと見れるようにする

---

## 概要

現在のTODO機能を拡張し、以下を実現する：
- ✅ 未完了/完了タスクの明確な視覚的分離
- 📊 進捗の視覚化（プログレスバー、統計）
- 📅 過去のTODO履歴の閲覧
- 📈 週次/月次の完了タスク分析
- 🎯 タスクのカテゴリ管理（オプション）

---

## 技術スタック

- **フロントエンド**: HTML5, Tailwind CSS, Vanilla JavaScript
- **アニメーション**: CSS Transitions/Animations
- **グラフ表示**: Chart.js または Tailwind CSSによる簡易実装
- **データベース**: Supabase PostgreSQL
