# Google Apps Script セットアップ手順

スプレッドシート自動出力機能のセットアップ方法

## 1. Google Apps Scriptプロジェクトの作成

1. Googleスプレッドシートを新規作成
2. `拡張機能` → `Apps Script` をクリック
3. プロジェクト名を「FDGroup勤怠自動出力」に変更

## 2. スクリプトのコピー

`auto-export.js` の内容を Apps Script エディタにコピー

## 3. スクリプトプロパティの設定
1. Apps Scriptエディタで `プロジェクトの設定` (歯車アイコン) をクリック
2. `スクリプト プロパティ` セクションで以下を追加:

| プロパティ名 | 値 |
|------------|-----|
| `SUPABASE_URL` | `https://thwfendgywwxbdjofbdt.supabase.co` |
| `SUPABASE_ANON_KEY` | Supabaseの匿名キー |
| `SPREADSHEET_ID` | スプレッドシートのID（URLから取得） |
| `SLACK_WEBHOOK_URL` | Slack Webhook URL（オプション） |

### スプレッドシートIDの取得方法

スプレッドシートのURLから取得:
```
https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit
```

## 4. トリガーの設定

1. Apps Scriptエディタで `トリガー` (時計アイコン) をクリック
2. `トリガーを追加` をクリック
3. 以下のように設定:
   - 実行する関数: `exportDailyAttendance`
   - 実行するデプロイ: `Head`
   - イベントのソース: `時間主導型`
   - 時間ベースのトリガータイプ: `日タイマー`
   - 時刻: `午前11時～正午`
4. `保存` をクリック

## 5. テスト実行

1. Apps Scriptエディタで `testExport` 関数を選択
2. `実行` ボタンをクリック
3. 初回実行時は権限の承認が必要
4. スプレッドシートにデータが出力されることを確認

## 6. 動作確認

### 正常に動作している場合

- 毎日11:00に自動実行される
- 前日の勤怠データがスプレッドシートに追加される
- ユーザーごとにシートが分かれている
- 月次集計が自動更新される

### トラブルシューティング

**データが出力されない場合:**
- スクリプトプロパティが正しく設定されているか確認
- Supabase URLとAPIキーが正しいか確認
- 実行ログ (`表示` → `ログ`) でエラーを確認

**権限エラーが出る場合:**
- トリガー設定時に必要な権限を承認する
- スプレッドシートへのアクセス権限があるか確認

## 7. Slack通知の設定（オプション）

Slack通知を有効にする場合:

1. Slack Incoming Webhookを作成
2. Webhook URLをスクリプトプロパティ `SLACK_WEBHOOK_URL` に設定
3. `auto-export.js` の該当コメントを解除

## 注意事項

- トリガーは毎日11:00に **前日** のデータを出力します
- 出力対象は `status = 'completed'` の勤怠データのみです
- ユーザーごとに個別のシートが作成されます
- 月次集計は自動的に更新されます
